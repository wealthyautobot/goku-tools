PDF Box Coordinate Tool

Pick a PDF to start

Each page renders below. Drag on any page to draw boxes. Coordinates are stored per page in PDF coordinate space.

How it works
• Drag on PDF to draw a box
• Drag a box to move it
• Click a box to select it
• Double-click a box to rename it
• Add/edit custom name for selected box
• Press Delete/Backspace to remove selected box
• Export gives page-wise JSON coordinates with names

Coordinate origin is top-left of the PDF page. Values are normalized to the PDF’s native page dimensions, so they remain valid independent of zoom/render size.
